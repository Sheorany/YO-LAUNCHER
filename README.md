# Minimal Launcher

A minimalist Android home screen:

- **Home** – big clock and date, your favourite apps as plain text, and 5 quick-open icons at the bottom.
- **Swipe up** – A–Z text list of all apps with search.
- **Swipe right (to the left page)** – one family photo each day, with caption.
- **Swipe left (to the right page)** – iPod-style click wheel that controls YT Music.

## Get the APK without a computer (GitHub)

1. Create a free account at github.com and make a new **empty** repository.
2. Upload every file in this folder to it, keeping the folders the same.
3. GitHub builds the app automatically. Open the **Actions** tab, tap the latest
   "Build APK" run, and download **MinimalLauncher-apk** at the bottom.
4. Unzip it on your phone and tap `app-debug.apk` to install
   (allow "Install unknown apps" when asked).

## Or build with Android Studio (computer)

Open this folder in Android Studio, connect your phone with USB debugging on,
and press Run.

## First use on the phone

1. Press the Home button and choose **Minimal Launcher → Always**
   (or Settings → Apps → Default apps → Home app).
2. **Home list:** tap "+ add app". Long-press a name to move, change or remove it.
3. **Quick icons:** tap an empty "+" to choose an app. Long-press an icon to change it.
4. **App list:** long-press any app to add it to home, set it as a quick icon, see app info or uninstall.
5. **Memories:** tap "+ add photos" and pick family photos. A different photo shows each day;
   tap the caption to write who and where. Long-press the photo to remove it.
6. **Music:** tap the light screen once and allow **Minimal Launcher music info**
   so it can show the song name and progress. MENU opens YT Music, the centre and
   bottom buttons play/pause, left and right skip.
